# Real Dashboard Worksheet (expanded)

**Source:** The Founder's Field Manual, Chapter 16 — Metrics That Matter at Every Stage
**Agent use:** When a subscriber asks which metrics to track, shows a dashboard with 20+ metrics, or cites vanity metrics (downloads, signups, cumulative anything). Core tool: the Metrics Pyramid — North Star alone at the top, 3–5 supporting KPIs below, operational metrics at the base.

## Step 1 — Name your North Star
The one metric that, if it moved, would mean the company moved. **If you have two, you have neither.** Good North Stars measure delivered value, not activity: weekly active teams completing a core workflow, not registered users.

*Agent check by model:* B2B SaaS → weekly/monthly active accounts using the core workflow; marketplace → completed transactions or GMV with take-rate context; consumer → retained active users at day 30+; usage-priced → consumed units tied to revenue.

## Step 2 — Name three to five supporting KPIs
Each must have a clear causal connection to the North Star. If it doesn't move the North Star, it belongs in the operational tier, not the top dashboard.

## Step 3 — Run the push-back test
Run every current top-dashboard metric through the chapter's six push-back questions. Anything failing three or more: cut from the top dashboard. The agent should be ruthless here — the exercise is about removing metrics, not adding them.

## Step 4 — Stage-check
Which stage is the company actually in?
- **Early:** activation, retention cohorts, qualitative signal. Revenue metrics can wait; retention cannot.
- **Scaling:** unit economics — CAC, LTV:CAC (rule of thumb ≥3), payback period, churn, burn multiple.
- **Mature (50,000+ users / near-profitable):** gross margin, efficiency ratios (Rule of 40 for SaaS), defensibility metrics.

Most common error: obsessing over the *previous* stage's metrics. Ask: what is the one metric you should be obsessing over now that you are not?

## Step 5 — Audit the metrics meeting
What decisions did the last metrics meeting produce? A dashboard that generates no decisions is decoration. Each top metric needs an owner and a pre-agreed threshold that triggers action.

## Common failure patterns
1. **Vanity dashboards** — cumulative charts that only go up. Replace with rates and cohorts.
2. **Averages hiding cohorts** — blended retention masking that recent cohorts are worse.
3. **Metric theater for investors** — one dashboard for the board, another for reality. Run the company on the real one.
4. **Premature unit-economics precision** — computing LTV from 4 months of data; the agent should flag confidence intervals when history is short.

## Output the agent should produce
The pyramid: one North Star (with the value-not-activity justification), 3–5 KPIs with causal links stated, the cut list from the push-back test, the stage call, and one metric-owner-threshold table.
